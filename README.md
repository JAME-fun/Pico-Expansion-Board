# Pico-Expansion-Board
The Pico Expansion board is a PCB with built in things such as: OLED, 2 Push Buttons, JST Connector for battery and of course a Raspberry Pi PICO.
### What you need/ Bill of Materials:
| Item | Quantity |
| :--- | :--- |
| Raspberry Pi Pico 2W | 1 |
| General Purpose Diode | 1 |
| JST PH 2-Pin Vertical Connector | 1 |
| 1x4 Pin Header | 1 |
| 6 x 6 x 5mm Tactile Push Buttons | 2 |
